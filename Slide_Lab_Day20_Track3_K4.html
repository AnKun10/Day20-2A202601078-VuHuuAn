•Shared state: một cấu trúc dữ liệu duy nhất — query, sources, research_notes, analysis_notes, final_answer, route_history
•Handoff: mỗi agent ghi kết quả vào state rồi trả quyền về Supervisor
•Guardrail: max_iterations, timeout, retry — cầu dao tự ngắt chống vòng lặp vô hạn

BƯỚC 2 SUPERVISOR & LANGGRAPH WORKFLOW 60 phút 
state chưa có sources        -> route "researcher"
state chưa có analysis_notes -> route "analyst"
state đủ dữ liệu             -> route "writer"
iteration >= max_iterations  -> STOP (guardrail)
•Routing policy — agents/supervisor.py: nhìn state hiện tại, quyết định bước tiếp theo
•Build graph — graph/workflow.py: node supervisor/researcher/analyst/writer + conditional edges
•Stop condition: dùng state.record_route() + max_iterations từ Settings
•Kết quả: make run-multi hết StudentTodoError ở workflow · route_history đúng thứ tự
Thời gian
60:00

⚠️ Bug kinh điển

Supervisor ↔ Researcher lặp vô hạn vì quên tăng iteration hoặc thiếu stop condition — đây là lý do guardrail tồn tại.

BƯỚC 3 WORKER AGENTS: RESEARCHER · ANALYST · WRITER 60 phút

🔍 Researcher

Gọi SearchClient (Tavily hoặc mock) → ghi sources + research_notes vào state

🧠 Analyst

Đọc research_notes → sinh analysis_notes: so sánh, đánh giá độ tin cậy nguồn

✍️ Writer

Tổng hợp thành final_answer có citation trỏ về sources

•Mỗi agent một vai trò rõ ràng, không overlap — role design là learning outcome chính
•Handoff qua shared state: agent làm xong ghi vào state rồi trả quyền về Supervisor
•Kết quả: chạy end-to-end ra final_answer có trích dẫn · state đủ dữ liệu trung gian để debug
