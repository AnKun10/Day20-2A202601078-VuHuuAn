# Notebooks

Optional area cho học viên tạo notebook demo. Production code vẫn nên nằm trong `src/`, không viết toàn bộ logic trong notebook.

## Nội dung

- `demo_multi_agent_walkthrough.ipynb` — notebook hướng dẫn từng bước: shared state → mock services → demo agents → supervisor routing → mini workflow → benchmark. Notebook chứa các ô `TODO(student)` bạn phải tự hoàn thành trước khi vòng lặp workflow chạy end-to-end. Sau khi hoàn thành, chuyển logic vào `src/multi_agent_research_lab/` theo bảng mapping ở cuối notebook.
